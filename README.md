# Pepper AdBlock - Remote Rules

File `rules.json` này là bộ rules công khai cho extension Pepper AdBlock (chặn quảng cáo YouTube & Facebook).

Extension tự tải file này mỗi 6 giờ (nguồn dự phòng sau Cloudflare R2) và áp dụng ngay, không cần cài lại.

Chỉ chứa selector CSS và nhãn nhận diện quảng cáo (ví dụ: "Được tài trợ", "Sponsored").
Không chứa mật khẩu, token hay dữ liệu cá nhân nào.

Nguồn chính: https://pub-c3d7ef17e3ae4baba53365e1ea22787a.r2.dev/pepper-adblock/rules.json
